# Clé en main !

Jeu de gestion immobilière en temps réel, pour téléphone (PWA). On part d'un salaire et d'un petit apport à Dole, et on bâtit un patrimoine : repérer les bonnes affaires, négocier, rénover pièce par pièce, louer, revendre, dans des villes réelles qui vivent sous nos yeux.
